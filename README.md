# お宝探しゲーム

左右の道を選びながら、ダンジョンの奥へ進んでお宝を集めるブラウザゲームです。
選ぶ道と現在の階層によって、探索の成功率と獲得できるポイントが変わります。

スタミナはハート3個分。失敗するたびに1個減り、すべてなくなるとゲームオーバーになって、集めたポイントもすべて没収されます。
さらに奥へ進んで高得点を狙うか、ポイントを失う前に入り口へ戻るかを判断します。全5階層を探索し、最終の5階層目で成功するとクリアです。

以下に、現在のルールと実装内容をまとめています。

## 遊び方

1. 1階層・スタミナ3・保有ポイント0・残り5ターンからスタートします。
2. 左右の道に表示された成功率と獲得ポイントを見て、進む道を選びます。
3. 成功するとポイントを獲得し、次の階層へ進みます。5階層目で成功すると、その階層のポイントを獲得してゲームクリアです。6階層へは進みません。
4. 失敗するとスタミナが1減り、同じ階層でもう一度挑戦します。成功・失敗にかかわらず、道を選ぶたびに1ターン消費します。
5. スタミナが0になるとゲームオーバーです。保有ポイントが0になり、探索の操作ができなくなります。
6. クリアする前に5ターンを使い切った場合は、探索終了です。スタミナが残っていれば、その時点のポイントを保持して結果を表示します。最終ターンにスタミナが0になった場合は、ゲームオーバーが優先されます。

「入り口へ戻る」を押すと、途中で探索を終了して、その時点のポイントを持ち帰れます。帰還時には到達階層と持ち帰ったポイントを表示します。
クリア・ゲームオーバー・ターン切れ・帰還の後は、左右の選択と帰還のボタンが無効になります。
「やり直す」は探索中も終了後も使えます。スタミナ・階層・ポイント・残りターン・道の成功率と獲得ポイント・結果表示を初期状態に戻し、すべての探索ボタンを再び使えるようにします。

## 道ごとの成功率と獲得ポイント

左の「整備された道」は成功しやすく、右の「崩れかけた道」は成功率が低い代わりに多くのポイントを獲得できます。
深い階層ほど成功率が下がり、成功したときの獲得ポイントが増えます。

| 挑戦する階層 | 左：成功率 | 左：獲得ポイント | 右：成功率 | 右：獲得ポイント |
| --- | --- | --- | --- | --- |
| 1階層 | 80% | 10pt | 60% | 20pt |
| 2階層 | 75% | 20pt | 50% | 40pt |
| 3階層 | 70% | 30pt | 40% | 60pt |
| 4階層 | 65% | 40pt | 30% | 80pt |
| 5階層 | 60% | 50pt | 20% | 100pt |

現在の階層を `n` とすると、コードでは以下の式で計算しています。

- 左の成功率：`80 - (n - 1) × 5`（%）
- 左の獲得ポイント：`n × 10`（pt）
- 右の成功率：`60 - (n - 1) × 10`（%）
- 右の獲得ポイント：`n × 20`（pt）

成功・失敗は、1〜100の整数をランダムに生成し、その数が成功率以下かどうかで判定します。
ポイントが加算されるのは成功したときだけです。失敗時はスタミナが減り、ゲームオーバーになるまでは保有ポイントを維持します。

## 実装済みの内容

- 左右の道の選択と、乱数による成功・失敗の判定
- 成功時の階層移動とポイント加算
- 階層に応じた成功率・獲得ポイントの更新
- 失敗時のスタミナ減少と、ハート画像の切り替え
- スタミナ0でのゲームオーバー、全ポイント没収、探索ボタンの無効化
- 5階層目の成功によるクリア判定と、最終階層のポイント加算
- 残りターン・現在の階層・保有ポイント・探索結果の表示
- 5ターン終了時の結果表示と、探索ボタンの無効化
- 「入り口へ戻る」での探索終了、ポイントの確定、到達階層の表示
- 「やり直す」での内部データと画面表示の初期化、探索ボタンの再有効化

## 起動方法

`index.html` をWebブラウザで開くと遊べます。VS Codeを利用している場合は、Live Serverなどで開くこともできます。
ビルドやパッケージのインストールは不要です。jQueryは `JavaScript/vendor/jquery-3.7.1.min.js` をローカルから読み込んでいます。

最初から遊び直す場合は、画面の「やり直す」を押してください。

## 使用技術

- HTML
- CSS（Grid・Flexbox）
- JavaScript
- jQuery 3.7.1
- SVG（ハート・矢印アイコン）

## 動作確認用テスト

Node.jsが利用できる環境で、プロジェクトのフォルダーから次のコマンドを実行できます。追加のパッケージは不要です。

```sh
node --test tests/game.test.cjs
```

ブラウザの代わりに表示要素とクリックイベントを用意し、実際のゲームコードで、成功率の境界・クリア・ゲームオーバー・ターン切れ・帰還・やり直しを確認します。
